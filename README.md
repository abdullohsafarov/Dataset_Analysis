# Анализ концентрации CO2 с помощью линейной регрессии

Проект анализирует временной ряд атмосферного CO2 с обсерватории Мауна-Лоа и строит простую линейную регрессию без использования `scikit-learn` и `scipy`.

Основная версия проекта оформлена в виде Jupyter notebook:

- [analysis.ipynb](analysis.ipynb) - пошаговый анализ и визуализация

---

## Что делает проект

- скачивает датасет CO2 из открытого источника
- очищает данные и оставляет только корректные наблюдения
- делит выборку на обучающую и тестовую части
- вычисляет параметры линейной регрессии вручную
- считает метрики качества модели
- строит и сохраняет графики в `output_plots/`

---

## Данные

Источник данных:

- `datasets/co2-ppm` на GitHub
- https://github.com/datasets/co2-ppm

Параметры набора данных:

- период: с марта 1958 года по настоящее время
- частота: ежемесячные наблюдения
- целевая переменная: `Average`
- признак: `Decimal_Date`

---

## Методика

Все основные вычисления реализованы вручную:

- среднее значение
- стандартное отклонение
- ковариация
- корреляция Пирсона
- линейная регрессия методом наименьших квадратов
- MAE
- MSE
- RMSE
- коэффициент детерминации `R²`

## Запуск

### 1. Создать окружение

```bash
py -3 -m venv .venv
```

### 2. Установить зависимости

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 3. Запустить notebook

Откройте [analysis.ipynb](analysis.ipynb) в Jupyter Notebook, JupyterLab или VS Code и выполните ячейки сверху вниз.
